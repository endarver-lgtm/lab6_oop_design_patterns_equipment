# Лабораторная работа №6. Порождающие паттерны в C++

Проект по курсу ООП (Вариант 10). Система учета и управления парком строительной техники (ООО «СтройТехИнвест») с практической реализацией способов конструирования полиморфных объектов.

---

## Проблема виртуальных конструкторов в C++

В стандарте C++ конструктор не может быть объявлен виртуальным по нескольким понятным причинам:
1. Виртуальный вызов опирается на указатель на таблицу виртуальных методов (`vptr`). До выполнения тела конструктора объект еще не инициализирован в памяти, и указатель `vptr` просто не настроен.
2. Для выделения памяти под объект компилятор должен точно знать его размер еще до создания.
3. Конструирование всегда идет от базового класса к наследникам, а виртуальный механизм ищет метод наследника.

При этом деструктор полиморфного базового класса обязательно должен быть виртуальным, чтобы при удалении через указатель на базовый тип корректно освобождались ресурсы наследников.

Для создания объектов нужных типов вместо виртуальных конструкторов используются порождающие паттерны проектирования.

---

## Реализованные способы создания объектов

В программе представлены 5 типов строительных машин (экскаватор, кран, бульдозер, самосвал, бетононасос) и 5 способов их создания:

1. **Фабричный метод (Factory Method)**
   - Базовый класс фабрики объявляет чисто виртуальный метод создания, а конкретные фабрики создают нужную спецтехнику.
2. **Параметризованная фабрика со спецификациями**
   - У каждого вида техники свой уникальный набор характеристик (объем ковша для экскаватора, вылет стрелы для крана, ширина отвала для бульдозера). Параметры упакованы в удобные структуры спецификаций.
3. **Реестр типов (EquipmentRegistry)**
   - Создание техники по ее строковому названию через ассоциативный массив функций-создателей. Позволяет добавлять новые типы машин без изменения существующего кода интерфейса.
4. **Полиморфная фабрика со связанным навесным оборудованием**
   - Техника создается в связке с подходящим навесным оборудованием (гидромолот для экскаватора, крюк для крана, бетоновод для насоса).
5. **Полиморфное клонирование (метод clone)**
   - Виртуальный конструктор копирования. Реализован через шаблонный класс `Cloner`, который избавляет от необходимости вручную писать метод `clone()` в каждом дочернем классе.

---

## Управление памятью

Для хранения техники используется управляющий класс `EquipmentManager`. Все объекты хранятся в векторе умных указателей `std::vector<std::unique_ptr<ConstructionEquipment>>`. Это полностью исключает утечки памяти: при удалении элемента или выходе из программы память освобождается автоматически.

## Структура проекта

```text
lab6/
├── ConstructionEquipment.h / .cpp – базовый класс строительной техники
├── DerivedEquipment.h / .cpp      – классы-наследники (Excavator, Crane, Bulldozer, DumpTruck, ConcretePump)
├── EquipmentAttachments.h         – иерархия навесного оборудования
├── EquipmentSpecs.h               – структуры параметров для создания техники
├── Factories.h / .cpp             – реализация фабричных методов
├── EquipmentRegistry.h / .cpp     – динамический реестр типов спецтехники
├── Cloner.h                       – шаблон для автоматического создания метода clone()
├── EquipmentManager.h / .cpp      – хранение списка техники и управление парком
├── Input.h                        – консольный ввод с контролем ошибок
├── main.cpp                       – меню программы и демонстрация работы паттернов
├── lab6.vcxproj                   – проект для Visual Studio 2022
└── README.md                      – описание работы
```

## Возможности программы

- Просмотр списка всей техники компании в виде таблицы с техническими параметрами;
- Добавление новой техники через любой из 5 порождающих паттернов;
- Клонирование существующей машины по ее номеру (демонстрация полиморфного копирования);
- Редактирование параметров и часовой ставки аренды;
- Удаление техники из реестра с автоматическим освобождением памяти;
- Расчет суммарной суточной стоимости аренды всего парка;
- Экспорт полного реестра в текстовый файл;
- Быстрая загрузка начальных тестовых данных.

## Сборка и запуск

Проект написан на стандарте C++17.

### Сборка через Visual Studio 2022:
Открыть `lab6.vcxproj` и собрать проект (Ctrl+Shift+B).

### Сборка через консоль (Developer Command Prompt):
```cmd
cd lab6
msbuild lab6.vcxproj /p:Configuration=Release /p:Platform=x64
..\x64\Release\lab6.exe
```

Либо через компилятор MSVC:
```cmd
cl /std:c++17 /EHsc *.cpp /Fe:lab6.exe
lab6.exe
```
